# Capsure closure page (static)

Plain HTML copy of the placeholder that was live at app.capsure.com.au on 21 Oct 2026.
Text, colors, spacing and the logo were taken from the live bundle (index-BQJOe1Xy.js); positions were checked element by element against the live page.

- No JavaScript, no tracking, no external requests. The Inter font and favicon are local files.
- `404.html` is a copy of `index.html`, so any path shows the notice.
- `.nojekyll` is for GitHub Pages.
- Hosting: upload this folder to GitHub Pages, Cloudflare Pages or Netlify (all free), then point `app` (and optionally `api`) at it in GoDaddy DNS.

The older `../closure-page/` is the 15 Oct React build. It loads a Reddit ad pixel, so use this folder instead.
